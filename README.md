## Requisitos

Python 3.10 o superior.

## Ejecución

Desde terminal:

```
git clone https://github.com/danielzamorap/EL4203-proyecto-progra-avanzada-EEG.git
cd EL4203-proyecto-progra-avanzada-EEG
python -m pip install -r requirements.txt
python src/main.py
```

El código usa `data/processed/demo.npz`, no es necesario descargar el dataset de CHB-MIT para ejecutarlo.
